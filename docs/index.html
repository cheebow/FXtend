効果音専用のプラグイン音源。
Impact も Riser も、ノートひとつで。

FXtend は、曲の展開をつなぐ効果音（Impact、Riser、Downlifter、Sweep、Clap、Sub Drop）を鳴らすためだけに作った VST3 / AU プラグインです。長さを「4 小節」のように決めて MIDI ノートを 1 個置けば、曲のテンポに合わせて、狙った位置でぴたりと鳴り終わります。

  • VST3
  • Audio Unit
  • スタンドアロン
  • macOS 12 以降
  • オープンソース（AGPLv3）

特長

曲作りの手を止めずに、効果音をさっと置けます。

長さは小節と拍で決める

「4 小節」と決めたら、ノートを置いた位置からきっちり 4 小節で鳴り終わります。ノートを長く伸ばしておく必要はありません。途中でテンポが変わっても、終わる位置はずれません。

サンプルがなくても鳴る

音はすべて内蔵のシンセ（Noise / Sub / FM / Transient / Clap）で作っています。61 種類の Factory プリセットは、追加のファイルなしですぐに使えます。

手持ちのサンプルも重ねられる

WAV / AIFF を 4 つまで読み込めます。音程はそのままに長さだけを合わせる Stretch のほか、Resample、Loop、One-shot から鳴らし方を選べます。

終わり方は 2 通り

Strict は、終わりの位置ですぱっと無音になります。Natural は、リバーブやディレイの響きだけを残します。

WAV に書き出せる

いま鳴らしている音を、テンポも長さもそのまま WAV ファイルにできます。オーディオトラックに貼って使いたいときに便利です。

別の Mac に持っていける

プリセットと、そこで使っているサンプルを、ひとつのファイル（.fxtendpack）にまとめられます。

6 つの FX タイプ

タイプごとにノブが 4 つあり、細かい設定を開かなくても音の雰囲気をすぐに変えられます。下の音はどれも Factory プリセットを 128 BPM・2 小節で書き出したものです。

Impact

ドンと一発鳴らす衝撃音。決めた長さのなかで響きが消えていきます。

画面

ウィンドウの大きさはそのままで、中身だけが切り替わります。画像をクリックすると大きく表示します。

使い方

基本は、プリセットを選んでノートを置くだけです。

  1. インストゥルメントトラックに FXtend を立ち上げて、プリセットか FX タイプを選びます。
  2. LENGTH で長さを決めます（たとえば 4 Bars）。それが何拍ぶんで何秒になるかは、すぐ横に表示されます。
  3. 鳴らしたい位置に MIDI ノートを 1 個置きます。ノートの高さや長さは音に関係ありません。音量はベロシティで変わります。
  4. TAIL で終わり方を選びます。Strict ならすぱっと無音に、Natural なら余韻が残ります。
  5. もっと作り込みたくなったら Advanced を開きます。Export WAV を押せば、そのままファイルに書き出せます。

DAW を止めたままノートを動かしたときの試聴は、鍵盤を離すとすぐ止まります。最後まで聞きたいときや、鳴らしたくないときは、STOPPED を Full か Off に切り替えてください。再生中の鳴り方は変わりません。

入手

インストーラをダウンロードして開き、画面の案内に沿って進めてください。VST3、Audio Unit、スタンドアロンアプリの中から、入れたいものを選べます。

インストーラをダウンロード（macOS）

ソースコードからビルドすることもできます。Xcode と CMake 3.24 以降が必要です。

git clone https://github.com/cheebow/FXtend.git
cd FXtend
cmake -B build -G Xcode
cmake --build build --config Release

ビルドが終わると、プラグインは ~/Library/Audio/Plug-Ins の VST3 と Components に入ります。削除の手順などは README をご覧ください。
